# covid19-supportnavi

東京都の「新型コロナウイルス感染症対策支援情報ナビ」をモデルにした、支援情報ナビゲーションサイトを迅速に作成できるオープンソースプロジェクトです。このツールは、対話型の質問フォームを通じて、市民や事業者が適切な行政サービスを見つけられるように支援します。

## 機能

- **対話型の質問フォーム:** 「あなたは事業者ですか、個人ですか？」といった一連の質問を通じて、利用者に合った支援制度をご案内します。
- **テーマ別閲覧:** テーマごとに分類されたすべての支援制度を閲覧できます。
- **データ駆動型コンテンツ:** ナビゲーターのロジックとサービス情報は2つのCSVファイルから読み込まれるため、コードを編集することなく簡単に更新できます。
- **カスタマイズ可能な外観:** CSS変数を編集することで、サイトのカラースキームを簡単に変更できます。デフォルトで3つのテーマ（デフォルト、ライト、ダーク）が提供されています。
- **アクセシビリティコントロール:** カラースキームの変更やフォントサイズの調整を行うためのUIコントロールが組み込まれています。
- **静的サイト:** 任意の静的ウェブホスティング環境にデプロイ可能な、完全な静的HTML、CSS、JSファイルを生成します。

## はじめに

### 前提条件

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/)

### インストール

1. リポジトリをローカルマシンにクローンします:
    ```bash
    git clone https://github.com/code4fukui/covid19-supportnavi.git
    cd covid19-supportnavi
    ```

2. 必要な依存関係をインストールします:
    ```bash
    npm install
    ```

### 開発モードでの実行

ローカル開発サーバーを起動するには、以下のコマンドを実行します:

```bash
npm start
```

これにより、`http://localhost:8080` でサーバーが起動します。開発モードでは、**更新したCSVファイルをブラウザウィンドウにドラッグ＆ドロップ**するだけで、新しいデータをテストできます。サイトがデータを読み込み、ナビゲーターが即座に更新されます。

### 本番用のビルド

デプロイ用の静的サイトファイルを生成するには、以下のコマンドを実行します:

```bash
npm run build
```

完全なサイト一式が `dist/` ディレクトリに生成されます。このディレクトリの内容をウェブホストにアップロードしてください。

## カスタマイズ

ナビゲーターをカスタマイズする主な方法は、独自のデータファイルを用意することです。

### サービス情報データ

このファイルには、各行政サービスの詳細が含まれています。
- **スキーマや詳細な手順については、`manual.pdf` 内の「行政サービス情報csvについて」を参照してください。**

### ナビゲーションロジックデータ

このファイルには、対話型ナビゲーターの質問、回答、および分岐ロジックが定義されています。
- **スキーマや詳細な手順については、`manual.pdf` 内の「ナビゲーションロジックcsvについて」を参照してください。**

### カラースキーム

サイトの外観を変更するには、以下のファイル内のCSS変数定義を編集します:

- `static/styles/color-def-default.css`（デフォルトテーマ）
- `static/styles/color-def-light.css`（ライトテーマ）
- `static/styles/color-def-dark.css`（ダークテーマ）
